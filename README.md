# قهرمان املا

**قهرمان املا** یک بازی/برنامهٔ تحت وب فارسی برای تمرین املا و تقویت دقت نوشتاری است. این پروژه به‌صورت یک صفحهٔ HTML منتشر شده و از طریق مرورگر قابل اجراست.

## اجرای آنلاین

برای اجرای نسخهٔ منتشرشده روی GitHub Pages از لینک زیر استفاده کنید:

**[اجرای آنلاین قهرمان املا](https://mhmdhsynbytrfan62-ux.github.io/farsi-app/)**

## ورود مدیر (حساب آزمایشی)

اطلاعات زیر برای ورود آزمایشی به بخش مدیر در نسخهٔ فعلی ارائه شده است:

| مورد | مقدار |
|---|---|
| نام کاربری | `admin` |
| رمز عبور | `1010` |

> **هشدار امنیتی:** مخزن GitHub این پروژه عمومی است؛ بنابراین این اطلاعات برای همه قابل مشاهده است. این حساب را فقط برای نمایش و آزمایش استفاده کنید و از این رمز برای حساب واقعی، اطلاعات شخصی یا سامانهٔ حساس استفاده نکنید. اگر قرار است پروژه به‌صورت جدی در اختیار کاربران قرار بگیرد، رمز را تغییر دهید و احراز هویت مدیر را به یک سرویس سمت سرور منتقل کنید. قرار دادن رمز در فایل HTML یا README آن را محرمانه نمی‌کند.

## نقش‌های کاربری

- **مدیر:** ورود به بخش مدیریت با حساب آزمایشی بالا.
- **بازیکن:** ورود به محیط بازی با حساب بازیکن مربوط به نسخهٔ فعلی برنامه.

اطلاعات ورود بازیکنان عادی در این راهنما درج نشده است؛ از اطلاعاتی که در خود برنامه برای حساب بازیکن تعریف شده استفاده کنید.

## روش استفاده

1. لینک «اجرای آنلاین قهرمان املا» را در مرورگر باز کنید.
2. در صفحهٔ ورود، نقش موردنظر خود را انتخاب کنید.
3. برای ورود آزمایشی مدیر، نام کاربری و رمز جدول بالا را وارد کنید.
4. برای بازی به‌عنوان بازیکن، از حساب بازیکن تعریف‌شده در نسخهٔ برنامه استفاده کنید.

## فناوری و ساختار پروژه

- HTML برای ساختار صفحه و محتوای برنامه.
- اجرا از طریق مرورگرهای به‌روز مانند Chrome، Edge و Firefox.
- میزبانی نسخهٔ آنلاین با **GitHub Pages**.
- فایل ورودی وب‌سایت: `index.html`.

## توسعه و به‌روزرسانی

فایل‌های پروژه در مخزن زیر نگهداری می‌شوند:

[مشاهدهٔ مخزن GitHub](https://github.com/mhmdhsynbytrfan62-ux/farsi-app)

## نکتهٔ حریم خصوصی

از واردکردن رمزهای شخصی، اطلاعات هویتی یا داده‌های محرمانه در نسخهٔ عمومی بازی خودداری کنید. محتوای یک مخزن عمومی و فایل‌های سمت مرورگر برای بازدیدکنندگان قابل مشاهده و بررسی است.
